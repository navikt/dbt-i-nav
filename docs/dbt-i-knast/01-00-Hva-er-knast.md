# Hva er Knast
Knast er ditt eget personlige utviklingsmiljø for analyse og behandling av data som bygges på toppen av Cloud Workstations i Google Cloud Platform. Det Linux basert utviklingsmiljø som kjører Docker-images i containere. Det er kun en IDE per Docker-image, og flere images er tilgjengelig i Knast.

Knast gir brukere firhet å velge fra utvalgte hardware resurser, åpening mot internet og interne Nav kilder.

Knast kan brukes både via nettleser eller remote via lokale IDEer (VS Code og Jetbrains). 

!!! warning "VIKTIG" 
    Remote utvikling er ikke tilgjengelig ved å jobbe mot DVH-baser.

Les mer om Knast [her](https://datadoc.ansatt.nav.no/produkter/knast/)

## Verktøy tilgjengelig i Knast for utvikling i dbt
- VS Code (code-oss) IDE, samt mulighet for VS Code Extensions
- Linux Terminal
- dbt-oracles
- Power User for dbt
- Python
- SQL Developer extension
- R
- Jupyter Notebooks extension
- Knast Secret Manager(KSM): Håndtering av DVH passordene på en trygg måte
